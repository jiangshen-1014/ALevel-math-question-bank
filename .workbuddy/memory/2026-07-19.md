## 新增功能：随章节随机组卷（generateRandomPaper）
- 需求：对每个科目从每个章节抽 1 道题随机组卷（尽量每章节 1 题），分值未满官方满分则随机重复某章节题目补足。
- 官方满分规则：`officialFullMarks(subject)` —— 科目 code 以 `P` 开头（纯数 Pure）→ 75 分；其余（M*/S* 力学/统计）→ 50 分。CIE/Edexcel 同规则（用户给定：P1/P3=75，S1/M1=50）。
- 章节来源：`CHAPTER_PRESETS[board|subject]`；若该科目无预设，则回退为「题库中该科目实际出现的章节」去重集合，保证任意科目都能用。
- 算法（`generateRandomPaper`）: ① 第一遍每章节随机抽 1 题（尽量不与已抽 id 重复，题不足才允许复用）；② 计算总分，若 < 满分则第二遍循环「随机选一个有题的章节→随机抽该章一题」补足（guard<500 防死循环）；③ `renderPaper` 渲染并弹预览，toast 报告 题数/总分/满分。
- 重构：`generatePaper`（组卷篮生成）抽成共享 `renderPaper(qs, {title, incSolution, boards})`，篮子生成与随机生成共用 → 两处逻辑统一、易维护。
- UI（index.html 组卷抽屉 foot 新增 `.rand-paper` 块）：`#f_randBoard`/`#f_randSubject` 两个 select（默认取当前侧栏 state.board/subject，打开抽屉时 `fillRandSelects()` 重填）+ `#randFullMarks` 实时显示该科目满分 + `#genRandomPaper` 按钮（复用 `#incSolution` 全局「含解析」开关）。绑定在 `bindEvents` 内。
- CSS（style.css）新增 `.rand-paper`/`.divider`/`.rand-row`/`select.mini`/`.rand-full` 样式。
- 校验：app.js `node --check` 通过；用真实 data.js 在 vm 内模拟 5 个科目 —— CIE S1(5章全覆盖,6题,52≥50)、CIE P3(11章全覆盖,11题,86≥75)、空科目(M1/Edexcel S1/Edexcel P1)返回 0 并触发 toast 不崩溃。
- 已同步部署副本 `public/`（index.html、assets/css/style.css、assets/js/app.js 均与 root 一致，public 为旧快照无部署专属内容，可安全覆盖）。改前 backup.py 已备三份（app.js/index.html/style.css）。
