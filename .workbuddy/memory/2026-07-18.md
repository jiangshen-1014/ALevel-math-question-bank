## 数学公式字重调细
- 需求：行内/独立数学公式整体偏粗，调细一点（试卷预览 F/G/H 斜体变量明显粗）。
- **根因**：MathJax v3 SVG 模式把 `font-weight` 写成 `<text>` 的 **XML 属性**（非 CSS style），CSS `!important` 无法覆盖。
- **方案修正v2**：`fira-math` 不是 MathJax v3 SVG 合法字体名（仅 `tex`/`STIX`/`STIX-Web`），导致全部公式崩溃（"Math output error"）。已回退为 `tex` 字体 + `scale: 0.92`（缩小比例使视觉上偏细）。**教训：MathJax v3 SVG 模式下字体粗细只能通过换合法 SVG 字体或缩放整体比例来调，不能随意写字体名。**
- **打印预览公式变粗根因**：`fontCache:'global'` 把字形放共享 `<defs>`、公式用 `<use href>` 引用；Chrome 打印/PDF 光栅化时该共享引用模型解析不稳，字形被叠画描重→视觉变粗。修复：改 `fontCache:'local'`（每公式内联字形路径，打印稳定、屏幕外观不变）。
- **⚠️ 关键结论（数学字重调细）**：MathJax v3 **SVG 模式字形是矢量路径，`font-weight`/`fontCache`/换字体（合法 SVG 字体仅 tex/STIX/STIX-Web，均偏重）全都改不了笔画粗细**——试过 CSS font-weight、JS 改属性、`fira-math`(非法名致崩溃)、`scale` 缩放均不达预期。唯一能让字重真正生效的是 **CHTML 模式**：数学是真实 HTML 文字，加 `mjx-container/.mjx-chtml { font-weight:300 !important }` 即可变细，屏幕+打印通用。已切 `tex-chtml-full.js` + `chtml:{scale:0.95}` + CSS 300。
- **S1 画图格纸组卷放大**：`.paper-grid img` 屏幕 max-width 320→480px（加 `width:100%`）；`@media print` 内加 `.paper-grid img { max-width:100%!important; width:620px!important }`，打印时接近 A4 内容宽度(≈688px)方便学生作图。用户反馈太大→回调为 340px（屏幕）/ 460px（打印）。
- **S1 小画图格纸选项**：新增 `hasSmallGrid` 字段 + `#f_hasSmallGrid` 勾选项（在大格纸下方）。适用于箱线图、茎叶图等小图表。小格纸图片 `data/images/grid_s1_small.png`（122KB）；渲染用 `.paper-grid.paper-grid-small` 类，屏幕 max-width 220px / 打印 300px。大格纸与小格纸可同时勾选（各自独立）。
