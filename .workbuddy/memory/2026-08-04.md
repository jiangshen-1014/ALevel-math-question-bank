## 网页编辑保存到本地 JSON 文件（用户需求：让网页版编辑保存到本地文件 json）
- 新增 `server/server.js`：零依赖 Node 内置 http 服务，静态托管项目根 + 提供 `/api/state`(GET 读覆盖/删除)、`/api/override`(POST 单题 upsert)、`/api/delete`(POST 单题删除)、`/api/replaceAll`(POST 批量替换)。持久化到 `data/store.json = {overrides:[...], deleted:[...]}`（仅存用户编辑增量，与种子合并）。启动：`node server/server.js`（默认端口 8787，可用 PORT 环境变量改）。
- `assets/js/data.js` 的 `Store` 增加 `_remote` 模式：`init()` 优先 `fetch('/api/state')`，成功则标记 `_remote=true` 并从服务器加载覆盖/删除（不再走 IndexedDB）；`upsert/remove/replaceAll` 在 `_remote` 时 `_post` 到服务器，否则保持原 IndexedDB/localStorage 降级。即：经服务器打开 → 编辑写本地文件；直接双击 index.html → 维持现状（IndexedDB），不破坏原行为。
- `assets/js/app.js`：启动时若 `Store.remote` 为真，toast 提示「已连接本地文件：编辑将保存到 data/store.json」。
- 校验：curl 实测 `/api/state` 初始为空；POST override 后磁盘 `data/store.json` 即时写入该题；POST delete 记录删除 id；重启服务后状态正确。已删除冗余的 `/api/export`(原用 eval 解析种子，脆弱；前端已有导出功能)。
- 注意：纯静态前端无法直接写本地文件，必须经本地服务器（或浏览器 FS Access API）。已交付 server 方案并保留 IndexedDB 降级。
- 端口清理：Git Bash 的 `taskkill //F` 对本环境无效，须用 PowerShell `Stop-Process -Id` 按 `Get-NetTCPConnection -LocalPort 8787` 的 OwningProcess 杀进程。
